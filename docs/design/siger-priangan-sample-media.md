# Siger Priangan sample media

**Purpose:** local, illustrative preview only. The people are fictional AI-generated adults. The images do not depict AyaWarta customers, a real wedding, or authenticated Sunda bridal attire. Cultural review of the complete template remains pending.

| Runtime asset | Size | Slot |
| --- | ---: | --- |
| `couple-portrait.webp` | 48,620 B | Cover portrait and third gallery item |
| `forest-walk.webp` | 104,190 B | Photo chapter and lead gallery item |
| `hands-detail.webp` | 61,054 B | Second gallery item |
| `groom-portrait.webp` | 4,782 B | Groom profile crop |
| `bride-portrait.webp` | 4,274 B | Bride profile crop |

All files reside in `public/themes/siger-priangan/sample/`. They were generated with the built-in `image_gen` tool and resized/encoded locally with Sharp. The five runtime files total 222,920 B. The cover portrait is part of the existing cover; below-fold chapter and gallery images use lazy loading.

**Generation direction:** cinematic, natural-light portraits of a fictional Indonesian couple in a misty West Java pine forest, contemporary dark green and ivory clothing with a restrained woven accent; a second scene shows the same fictional couple walking away together along a forest path; a third is a close detail of their linked hands and fabric. No text, logos, sacred symbols, specific bridal headdress, or copied textile motif was requested. The crop files are derived from the generated couple portrait.

These static files make the sample reproducible without Neon or Cloudinary writes. Customer data continues to select customer-owned images; the sample files are never used as an implicit fallback for an invitation slug.
