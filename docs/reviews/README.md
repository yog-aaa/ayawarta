# Stage Review Records

Store one review record per accepted or rejected implementation stage in this directory.

Recommended names:

```text
stage-00-baseline-review.md
stage-01-tooling-review.md
stage-02-prisma-review.md
```

Copy `STAGE-REVIEW-TEMPLATE.md` and record evidence from the programmer handoff plus the independent reviewer findings. A stage is not accepted merely because its implementation is committed.
